## 1. What is the difference between Linear Search and Binary Search?

### Answer

Linear Search checks each element one by one until the target is found.

Binary Search works only on sorted arrays. It repeatedly divides the search space in half.

### Complexity

| Algorithm     | Best | Worst    |
| ------------- | ---- | -------- |
| Linear Search | O(1) | O(n)     |
| Binary Search | O(1) | O(log n) |

### Example

```python
# Linear Search
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

```python
# Binary Search
def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid

        elif arr[mid] < target:
            left = mid + 1

        else:
            right = mid - 1

    return -1
```

## 2. What is a Hash Table?

### Answer

A hash table stores key-value pairs using a hash function.

Python dictionaries are implemented using hash tables.

### Time Complexity

| Operation | Average Complexity |
| --------- | ------------------ |
| Insert    | O(1)               |
| Search    | O(1)               |
| Delete    | O(1)               |

Worst case can become O(n) because of collisions.

### Example

```python
student = {
    "name": "John",
    "age": 20
}

print(student["name"])
```

## 4. What are Dockerfile best practices?

### Answer

Some important best practices are:

1. Use small base images
2. Minimize layers
3. Use `.dockerignore`
4. Avoid storing secrets in Dockerfiles
5. Use multi-stage builds
6. Pin dependency versions

### Example

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "main.py"]
```

---

## 5. What is Multi-Stage Build in Docker?

### Answer

A multi-stage build reduces image size by separating build dependencies from runtime dependencies.

### Example

```dockerfile
# Build stage
FROM python:3.11 AS builder

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

# Runtime stage
FROM python:3.11-slim

WORKDIR /app

COPY --from=builder /usr/local/lib/python3.11 /usr/local/lib/python3.11

COPY . .

CMD ["python", "main.py"]
```

## 6. How do Kubernetes Rollbacks work?

### Answer

Kubernetes allows reverting to a previous deployment version if a new deployment fails.

### Commands

```bash
kubectl rollout history deployment/myapp
```

```bash
kubectl rollout undo deployment/myapp
```

This helps maintain application stability during failed deployments.

## 9. Find the Longest Streak of Consecutive Numbers

### Question

Given:

```python
arr = [1,1,0,1,1,1]
```

Find the longest streak of `1`s.

### Answer

```python
def longest_streak(arr):
    max_count = 0
    current = 0

    for num in arr:
        if num == 1:
            current += 1
            max_count = max(max_count, current)
        else:
            current = 0

    return max_count

print(longest_streak([1,1,0,1,1,1]))
```

Output:

```python
3
```

## 12. What is Dependency Injection in FastAPI?

### Answer

Dependency Injection allows reusable logic like authentication or database connections.

### Example

```python
from fastapi import Depends, FastAPI

app = FastAPI()

def get_db():
    return "database"

@app.get("/")
def home(db = Depends(get_db)):
    return {"db": db}
```

---

### Example


* APIs

## 15. What is GitHub Actions?

### Answer

GitHub Actions is a CI/CD tool used to automate workflows.

### Example Workflow

```yaml
name: Python App

on: [push]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Install dependencies
        run: pip install -r requirements.txt

      - name: Run tests
        run: pytest
```
